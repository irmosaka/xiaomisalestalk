# Retail Sales Hub

یک وب‌اپلیکیشن فارسی و واکنش‌گرا برای مرور کاتالوگ محصولات و توسعه راهنمای فروش خرده‌فروشی.

## امکانات نسخه اولیه
- دسته‌بندی محصولات بر اساس خانواده قابل فهم برای تیم فروش
- فیلتر برند و دسته‌بندی
- جست‌وجوی نام محصول، مدل و EAN
- مرتب‌سازی بر اساس موجودی، نام و برند
- نمایش جزئیات هر SKU
- طراحی موبایل‌فرندلی و بدون نیاز به نصب وابستگی یا build
s در همان بخش نمایش داده می‌شود.

## نکته درباره داده‌ها
داده‌های پایه شامل نام کالا، برند، EAN، کد دسته‌بندی منبع و موجودی است. قیمت تمام‌شده و حاشیه سود در این نسخه وارد نشده‌اند تا اطلاعات داخلی مالی در راهنمای قابل مشاهده برای فروشگاه منتشر نشوند. قیمت بازار و قیمت خرید نیز تا زمان اعتبارسنجی و تعیین سطح دسترسی نمایش داده نمی‌شوند.

دسته‌بندی فارسی از روی کدهای Category موجود در فایل ورودی نگاشت شده است؛ بنابراین در مواردی که کد منبع مبهم یا عمومی بوده، دسته‌بندی نیازمند بازبینی انسانی است. متن‌های تخصصی Sales Talk و ادعاهای فنی عمداً خالی گذاشته شده‌اند تا پس از راستی‌آزمایی منابع رسمی تکمیل شوند.
